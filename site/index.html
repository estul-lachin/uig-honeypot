    How it works

    Cowrie listens on ports 22 and 23 and pretends to be a Linux server. It runs in a locked-down container that cannot open outbound connections, so attackers can't use it against anyone else. Every hour a script turns the raw logs into the aggregated JSON this page reads: IP addresses are reduced to country, city and coordinates rounded to about 10 km; URLs and IPs inside commands are defanged (hxxp[:]//). The raw logs stay on the server. Setup, hardening and the aggregation code are in the source repository.
