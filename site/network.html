Network view

Cowrie only sees what reaches its SSH and Telnet ports. Suricata watches every packet that reaches the VPS, as a passive IDS with the ET Open rules: it never blocks, it only alerts. This page counts the alerts on incoming traffic over the last 30 days. Sources are only counted, never listed, and no IP addresses are published.

About the sensor

Rules that only fire on the VPS's own traffic (its updates, its TLS to the cloud provider, Cowrie's replies) are turned off in disable.conf; everything an outside host sends stays on, however noisy. Alerts on outgoing traffic are counted but not shown. The same alerts go to Microsoft Sentinel. Set-up: vps/suricata.
